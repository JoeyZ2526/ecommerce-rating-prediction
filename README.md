# 电商评论评分预测：文本与结构化特征联合建模

**香港理工大学课程 Kaggle 竞赛项目**

面向 **5,173,005 条训练评论**，设计并实现文本与结构化信息联合建模流程，融合评论语义、用户评分习惯、商品历史评价和时间特征，通过 **PySpark + Word2Vec / TF-IDF + LightGBM** 完成大规模评分预测。

[查看比赛](https://www.kaggle.com/competitions/comp-5434-2025-s-2-project)

| 训练数据规模 | **5,173,005 条评论** |

本项目为香港理工大学课程团队竞赛项目。本人主要负责三层特征工程的设计与实现，包括文本表示、用户 / 商品 / 时间特征构建及多源特征融合，并参与处理内存不足、中间数据关联异常和模型对照问题。

## 项目概述

评分预测不仅取决于评论内容，也与用户的打分习惯、商品的历史评价和评论发生的时间有关。项目将这些信息统一组织为可训练的特征，完成从原始评论处理到测试集评分预测的完整建模流程。

- **文本与业务信息联合建模：**将标题、正文的语义向量与用户、商品、时间及交互特征融合，构建 328 维模型输入。
- **百万级数据处理：**基于 PySpark 完成批量清洗、文本表示和特征关联，以 Parquet 组织各阶段数据。
- **用户与商品画像：**构建评论数量、平滑历史评分、用户活跃度及用户商品偏好差异等特征，将历史行为转化为预测信号。
- **数据一致性治理：**定位中间特征关联造成的重复记录与列错位问题，加入行数、唯一 ID、关键字段及合并前后的一致性检查。
- **内存与计算流程优化：**通过分阶段处理、缓存释放、分块读取、float32 和内存映射矩阵，处理大规模特征构建中的内存压力。
- **模型与表示对照：**实现 Word2Vec 均值、TF-IDF 加权和最大池化三种文本路线，支持 LightGBM / XGBoost 模型切换，最终采用 LightGBM + V1 方案取得私榜第一。

## 技术路线

```text
评论标题、正文 + 用户、商品、时间等信息
    |
    v
Layer 1：文本清洗、分词、Word2Vec、TF-IDF
    |
    +--> V1：Word2Vec 均值表示 ----------------------+
    |                                             |
    +--> Layer 2：TF-IDF 加权 / 最大池化对照 --------+
                                                  |
                                                  v
Layer 3：用户画像 + 商品画像 + 时间特征 + 交互特征
                                                  |
                                                  v
         328 维融合特征 -> LightGBM / XGBoost -> 评分预测
```

### Layer 1：基础文本特征

分别处理标题和评论，完成空值处理、分词与停用词移除，训练 Word2Vec 和 TF-IDF 表示。

- 标题和评论分别生成 **150 维 Word2Vec 向量**。
- 使用 CountVectorizer 与 IDF 提取词项信息。
- 通过记录 ID 关联文本特征和结构化数据，以 Parquet 保存结果。

代码：[layer1_fixed.ipynb](layer1_fixed.ipynb)

### Layer 2：文本表示对照

实现两种增强表示，并与基础均值表示进行比较：

- **TF-IDF 加权：**按照词项权重聚合词向量。
- **最大池化：**提取词向量各维度的最大响应。

将标题、评论及合并结果分阶段处理，结合中间缓存复用和数据一致性检查，组织大规模文本特征计算。最终 V1 方案直接使用 Layer 1 的均值表示。

代码：[layer2_text_fixed_OOM_C&D.ipynb](layer2_text_fixed_OOM_C&D.ipynb)

### Layer 3：特征融合与预测

围绕用户、商品及两者之间的关系构建结构化特征，并与文本表示联合训练回归模型。

| 特征组 | 具体内容 | 维度 |
| --- | --- | ---: |
| 结构化特征 | 投票数、购买标记、时间、用户与商品统计、偏好差异等 | 17 |
| 标题语义 | 标题 Word2Vec 向量 | 150 |
| 评论语义 | 评论 Word2Vec 向量 | 150 |
| 文本相关性 | 标题与评论向量的余弦相似度 | 1 |
| 文本统计 | 向量范数、范数差异及 TF-IDF 统计 | 10 |
| **合计** | | **328** |

用户和商品评分统计采用平滑处理；训练样本通过留一处理减去自身评分贡献，测试样本映射训练数据形成的统计表。模型输入通过分块读取写入内存映射矩阵，再进行整体拟合，预测结果限定在 1–5 分区间。

代码：[layer3_reset_transVM.ipynb](layer3_reset_transVM.ipynb)

## 工程实践

### 解决特征关联异常

在多阶段特征处理过程中，识别到重复 ID 关联引起的行数膨胀和字段异常。通过检查原始输入、分层输出和合并结果，定位异常所在环节，并加入记录数量、ID 唯一性与关键字段校验，保证后续建模的数据对应关系。

### 组织大规模训练数据

将 Spark 特征处理与模型训练分开，通过 Parquet 连接两个阶段；训练阶段采用分块读取和 float32 内存映射矩阵，减少一次性加载与拼接全部特征带来的 Python 内存压力。

### 通过对照选择最终方案

实现不同文本表示和树模型组合，以实验结果选择最终方案。最终采用 **Word2Vec 均值表示 + 结构化特征 + LightGBM**，在课程竞赛最终私榜取得 **RMSE 0.86617、13 组第 1 名**。

- **预测建模：**LightGBM、XGBoost、scikit-learn
- **开发与计算：**Jupyter、Spark 本地计算、分块读取、内存映射
